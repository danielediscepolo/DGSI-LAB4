Questa cartella contiene i principali file Python usati durante i vari step della lecture 4:

- main.py -> test iniziale con un solo tool call SQL
- step2_loop.py -> loop multi-step con CREATE / INSERT / SELECT
- step3_wget.py -> tool wget con conferma utente + salvataggio users
- step5_error_test.py -> test errori USER DENIED / WGET ERROR / SQL ERROR
- step5_sql_error.py -> test separato per errore SQL

Per eseguire i file:
1. crea e attiva un virtual environment
2. installa openai e python-dotenv
3. crea un file .env basato su .env.example
4. esegui python <nomefile.py>
